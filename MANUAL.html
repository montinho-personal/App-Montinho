Coloque o app no ar e deixe com a sua cara — conversando com o Claude

Você recebeu o código-fonte de um app de acompanhamento para personal trainer. Este manual mostra como instalar, personalizar e modificar tudo pedindo em português ao Claude Code. Ele edita o código por você.

A ideia em uma frase:

Você não digita código. Você abre o Claude Code dentro da pasta do app e descreve o que quer — trocar a cor, o nome, a logo, adicionar uma tela. Sempre que aparecer um bloco roxo neste manual, é um pedido pronto: clique nele para copiar e cole no Claude.

O que é cada coisa App do aluno (celular): treino do dia, dieta, evolução e check-in. Painel do treinador (computador): cadastra alunos, monta treinos (prescrição), templates, biblioteca e acompanha a evolução.

Etapa 1

1 Instalar o necessário

Você faz isto uma vez só no seu computador.

ProgramaPara quêOnde baixar
Node.js (versão 20+)O “motor” que roda o appnodejs.org (botão LTS)
Claude CodeSeu assistente que edita o códigoclaude.com/claude-code
VS Code (opcional)Editor para abrir a pasta e o terminalcode.visualstudio.com

Conferir se o Node instalou

Abra o Terminal (Mac) ou o Prompt de Comando (Windows) e digite:

terminal
node --version

Se aparecer v20.x.x (ou maior), está tudo certo.

Etapa 2

2 Abrir o projeto e rodar o app

Descompacte a pasta do app que você baixou e deixe-a num lugar fácil (ex.: na Mesa / Desktop).

A. Abrir o Claude Code dentro da pasta

No Terminal, entre na pasta do app e abra o Claude. Troque CAMINHO/DA/PASTA pelo local onde você descompactou (dica: arraste a pasta para dentro do Terminal e ele preenche o caminho).

terminal
# entrar na pasta do app
cd CAMINHO/DA/PASTA/squad-app

# abrir o assistente
claude

B. Pedir para o Claude instalar e rodar

Com o Claude aberto, é só pedir:

▸ Cole no Claude Code copiar
“Instala as dependências deste projeto e roda o app em modo de desenvolvimento. Quando estiver no ar, me diz qual endereço abrir no navegador.”

Prefere fazer na mão? São dois comandos:

terminal
# só na primeira vez (baixa o necessário)
npm install

# sobe o app
npm run dev

Abra no navegador:

  • Painel do treinador: http://localhost:3000/treinador
  • App do aluno: http://localhost:3000/aluno
Já funciona sem configurar nada O app abre em modo demonstração, com alunos e treinos de exemplo. É perfeito para você ver tudo funcionando antes de conectar um banco de dados de verdade (Etapa 4).
Para parar o app Volte ao Terminal e aperte Ctrl + C.

Etapa 3

3 Deixar com a sua cara

Quase tudo da identidade (nome, cores, logo, contatos) fica em um único arquivo:

arquivo
src/config/brand.ts

Você pode editar esse arquivo na mão (são só os textos entre aspas e os códigos de cor #xxxxxx) ou — mais fácil — pedir ao Claude. Exemplos:

▸ Cole no Claude Code copiar
“Troca a cor de destaque do app para verde-esmeralda (#16a34a) e o nome para FELIPE TEAM. Mostra como ficou.”
▸ Cole no Claude Code copiar
“Salvei minha logo em public/brand/logo.svg. Faz o app usar minha imagem no lugar do logotipo de texto.”
▸ Cole no Claude Code copiar
“Pega as cores da minha marca (vou colar um print do meu Instagram) e aplica a paleta no app, mantendo o tema escuro.”
Por que é tão fácil As cores definidas em brand.ts são aplicadas no app inteiro automaticamente. Mudou ali → o app todo muda. Salve o arquivo, atualize o navegador (F5) e veja na hora.

Etapa 4

4 Conectar o banco e publicar na internet

Até aqui os dados são de exemplo. Para ter dados reais e o app acessível de qualquer lugar, você vai usar 3 serviços — todos com conta sua e plano gratuito para começar.

ServiçoPara quê
SupabaseBanco de dados + login dos alunos
GitHubGuardar o código com segurança
VercelColocar o app no ar (link público)

Tem um guia técnico detalhado no arquivo SETUP.md da pasta. Mas você pode fazer tudo com o Claude te guiando passo a passo. Comece assim:

▸ Cole no Claude Code copiar
“Quero publicar este app de verdade. Me guia, um passo de cada vez, para: 1) criar meu banco no Supabase e rodar as migrations, 2) subir o código no meu GitHub, 3) publicar na Vercel com as variáveis de ambiente. Espera eu concluir cada passo antes de ir pro próximo.”
▸ Cole no Claude Code copiar
“Já criei meu projeto no Supabase. Me explica exatamente onde pego a URL e as chaves (anon e service_role) e onde colo elas no arquivo .env.local.”
Segurança — leia com atenção As chaves do Supabase e o arquivo .env.local são senhas. Nunca compartilhe e nunca cole em chat público. O projeto já vem configurado para não enviar essas senhas para o GitHub — não mexa nessa proteção.

5 dicas de ouro ao conversar com o Claude
  1. Um pedido de cada vez. Mudanças pequenas são mais fáceis de revisar.
  2. Diga o que quer ver, não como fazer. “Quero os cards mais espaçados” > explicar CSS.
  3. Teste depois de cada mudança com npm run dev.
  4. Antes de mexidas grandes, peça: “faz um commit chamado ‘antes de mexer no layout’” — assim dá para voltar.
  5. Na dúvida, pergunte. O Claude conhece este projeto (há um arquivo CLAUDE.md que o orienta).
